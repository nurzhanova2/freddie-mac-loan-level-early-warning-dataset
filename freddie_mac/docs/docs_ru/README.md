# Разделы диссертации — русский язык

В этой папке хранятся русскоязычные методологические разделы, подготовленные
после выполнения соответствующих этапов работы с данными.

Файлы со статусом `draft` являются шаблонами и не описывают результаты,
которые ещё не подтверждены данными. После завершения этапа они заменяются
верифицированной версией с фактическими параметрами, версиями файлов и датами.
