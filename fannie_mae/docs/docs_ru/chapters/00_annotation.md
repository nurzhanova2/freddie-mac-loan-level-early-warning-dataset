# Аннотация исследования

## Тема исследования

**«Объяснимый искусственный интеллект для раннего выявления кредитного риска и
скрытого ухудшения качества заёмщика».**

## Практический результат

Практическим результатом исследования является прототип объяснимой
информационно-аналитической системы раннего предупреждения ипотечного
кредитного риска, построенный в соответствии с принципами SupTech. Система
преобразует доступные на дату наблюдения характеристики кредита в оценку риска
ухудшения, интерпретацию факторов риска и сигнал для приоритизации экспертной
проверки.

Научная значимость работы состоит в разработке воспроизводимого подхода к
раннему выявлению риска и скрытого ухудшения качества ипотечного кредита на
основе методов объяснимого искусственного интеллекта, временной валидации и
контроля утечки информации.
