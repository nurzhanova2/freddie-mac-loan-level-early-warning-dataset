# Аннотация исследования

## Официальная тема

**«Объяснимый искусственный интеллект для раннего выявления кредитного риска и
скрытого ухудшения качества заёмщика».**

## Практический результат

Практическим результатом исследования является **SupTech-inspired прототип
объяснимой системы раннего предупреждения ипотечного кредитного риска**. Он
преобразует доступные на дату наблюдения данные о кредите в ранний score,
сигнал ухудшения, объяснение факторов риска и trigger для приоритизации
человеческой проверки.

Формулировка не изменяет официальную тему: Explainable AI остаётся методом,
раннее выявление риска — задачей, а скрытое ухудшение качества — целевым
явлением. SupTech-inspired architecture описывает прикладной способ
использования результатов, а не утверждает, что работа является внедрённой
системой центрального банка.
