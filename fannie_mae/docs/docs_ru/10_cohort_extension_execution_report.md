# Этап 10. Расширение выборки Fannie Mae по acquisition cohorts

**Статус: выполнено для фиксированной выборки этапа 10.** К исходному пилоту 2008Q1 добавлены 2006Q1,
2012Q1, 2016Q1, 2020Q1, 2022Q1 и 2024Q1. Каждый архив прошёл отдельную validation, очистку,
построение panel и outcomes v01. Raw-архивы не объединялись и не изменялись.

Суммарно создано 185,931,842 loan-month наблюдений и 3,343,420 уникальных
кредитов (сумма по cohort; один и тот же кредит не переходит между acquisition
cohorts). Rates рассчитаны только
среди размеченных, нецензурированных risk-set наблюдений для соответствующего
outcome v01; это не является оценкой частоты по всем raw-строкам.

Сводный машинно-читаемый отчёт: [CSV](../../reports/fannie_cohort_summary_v01.csv)
и [JSON](../../reports/fannie_cohort_summary_v01.json).

Итоговое объединение выполняется лишь на processed-уровне с обязательной
переменной acquisition cohort и без смешения с Freddie Mac. Последующее
расширение до полной годовой Q1-выборки будет использовать тот же конвейер, но
не является условием начала этапов feature engineering и моделирования.
