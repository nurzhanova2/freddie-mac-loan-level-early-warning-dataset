# Этап 18. Построение панелей и исходов Q3-когорт

Все девять Q3-когорт подготовлены по той же спецификации, что и основная
Q1-выборка. Для каждой когорты сформированы аналитическая панель «кредит–месяц»,
event metadata и шестимесячные исходы `formal_adverse_6m` и
`early_deterioration_6m`. Полная очищенная копия 113 полей намеренно не
сохранялась: для экономии дискового пространства использовалась компактная
панель из допустимых для анализа полей, при неизменных правилах очистки,
словаре и контроле утечки.

Глобальная уникальность ключа «кредит–месяц» проверяется на
стандартизированных панелях в последующих аналитических запросах. Q3-панели
не включены в обучение v01; их назначение — независимая проверка устойчивости
фиксированных Q1-моделей.
